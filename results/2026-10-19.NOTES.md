# 2026-10-19 crawl — data caveats

Raw output of `node scripts/audit.mjs --out results/2026-10-19.json`, run from a Claude cloud session (Playwright 1.64.1, headless Chromium). All six storefronts answered 200 on `/`.

**Invalid records — do not diff against them:**

- `golden-harvest.ca` `/products`, `/products/category/flower` (all widths)
- `416cannabis.ca` `/products`, `/products/category/pre-rolls` (all widths)

These four routes returned HTTP 403 with Cloudflare's "Performing security verification" challenge to the cloud browser, so the measurements describe the challenge page (no header, 0 images, 0 low-stock badges), not the storefront.

- `queenscannabis.ca` `/` at 768: no header and one image recorded. It looks like the location-picker redirect was caught partway through; a separate load straight after rendered normally. Treat this one record as unreliable.

Everything else looked like real page data.
